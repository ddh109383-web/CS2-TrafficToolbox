## 操作
1. 点击左上角“道路禁止变道”图标，进入本 mod 的路段选择工具。
2. 指向道路，查看按道路实际形状显示的路段高亮；左键只选两个相邻节点之间的连接段，不按道路名称扩展整条路。指向节点时根据鼠标位置选择最近的相邻道路段。
3. 点击后在点击位置旁弹出紧凑面板，拖动标题栏可移动。面板会避开屏幕边缘；展开区域可滚动。
4. 在对应方向的路面开关上开启或关闭规则，在面板中选择另一段道路、开始或停止全部已启用路口的车辆记录。
5. 展开“更多操作与诊断”，可导出此路段及相邻路口、查看记录路径/统计/状态、清除全部规则并恢复原版导航。
6. 点 ×、按 Esc 或右键退出选择工具和面板。规则继续生效；正在进行的记录也继续，重新打开工具可停止记录。切换游戏其他工具时面板自动隐藏。

范围仍包含所选路段及两端节点，保留合法转弯。这是选择已有相邻节点间的路段，不会插入节点或修改道路几何。当前选择层支持地面及高架道路。

首次安装没有任何道路规则，原版导航保持启用。规则保存到城市存档；读取已设置规则的存档会自动恢复执行。开启时已经开始的变道不会被瞬间取消。

市政服务车辆（道路／公园维护、垃圾、邮政、警车、消防、救护与灵车）默认遵守禁变道；连续两次独立寻路失败或路径无法执行后，临时交回原版选道。成功获得可执行的受限路线会清零连续失败次数；同一次失败不会按帧重复计数。更换目的地或离开受限路段及相邻路口范围后恢复限制，正在进行的变道先完成。该临时状态不写入存档。

## 实现与范围
- 仅沿真实物理车道连接规划，保留 Traffic 生成的连线，不删除 Master/Slave，不改信号灯配时。
- 对约束范围中的未来车道进行连续性规划，在原版选道位置实施限制，而非只修改显示路径。
- 错道时生成合法驶出序列，等待整车（包括挂车）驶离后请求原目的地路线。没有合法出口时不会通过放开横切来解决。
- 原版导航 Actions 与路口预留/运动流程保留。替换执行器与原版导航不得同时运行；发现其他命名可识别的 CarNavigation 替换系统会暂停并显示原因。此检查不能识别所有 Harmony 补丁，不保证与任何交通 MOD 都兼容。
- 只支持本次构建所核对的 Game.dll，游戏更新后需要复核。
- 不支持的双向物理车道、中段连接及受限区域内停车/特殊终点可能停止等待或无法完成行程，需实测后补齐。先在普通单向分隔的机动车车道测试。
- 道路重建会重新检查连通性。找不到恢复路线时可能等待；不要把车辆未动理解为测试通过。
